개인정보처리방침

시행일: 2026년 11월 17일 · 서비스: 우리 캘린더

우리 캘린더(이하 "서비스")는 이용자의 개인정보를 「개인정보 보호법」에 따라 처리하며, 아래와 같이 안내합니다.

1. 수집하는 개인정보와 목적

항목목적보유 기간
로그인 계정 식별자, 이메일 — 카카오·Google·Apple 로그인 시 이용자가 동의한 범위회원 식별, 로그인 유지회원 탈퇴 시 즉시 삭제

일정표 사진AI로 사진에서 일정을 읽어오기처리 직후 폐기, 서비스에 저장하지 않음

서비스는 광고 목적의 추적, 위치 정보, 연락처를 수집하지 않습니다. 일정 알림은 휴대폰 안에서만 예약되며 서버로 보내지 않습니다. 화면 설정(위젯, 글자 크기, 테마)은 휴대폰에만 저장됩니다.

2. 처리 위탁 및 국외 이전

서비스 운영을 위해 아래 업체에 처리를 맡깁니다.

  • Supabase Inc. — 회원 인증, 데이터·사진 저장 (서버 지역은 프로젝트 설정에 따름)
  • 카카오, Google, Apple — 소셜 로그인 인증

아래와 같이 개인정보가 국외로 이전됩니다.

받는 자국가항목목적·시점보유 기간
Anthropic, PBC (privacy@anthropic.com)미국이용자가 올린 일정표 사진사진에서 일정 읽기, 이용자가 '일정 읽어오기'를 누를 때 암호화 통신으로 전송Anthropic의 API 데이터 정책에 따름 (AI 학습에 쓰이지 않음)
Supabase Inc.프로젝트 지역 (예: 서울 리전 선택 시 국내)위 1번의 저장 항목서비스 제공, 이용 중 상시회원 탈퇴 시까지

국외 이전을 원하지 않으면 사진으로 일정 추가 기능을 쓰지 않거나 회원 탈퇴를 할 수 있습니다. 이 경우 직접 입력하는 일정 기능은 계속 쓸 수 있습니다.

3. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 조회·수정·삭제하거나 처리 정지를 요구할 수 있습니다. 앱의 설정 > 내 계정 > 회원 탈퇴에서 계정과 모든 데이터를 즉시 삭제할 수 있습니다. 앱을 쓸 수 없는 경우 계정 삭제 안내를 참고하세요.

4. 파기

회원 탈퇴 시 계정 정보, 닉네임, 커플 연결 정보, 내가 만든 일정, 내가 올린 사진, 커뮤니티 글·사진·댓글·좋아요·신고·차단 기록을 지체 없이 복구할 수 없는 방법으로 삭제합니다.

5. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않습니다.

6. 안전성 확보 조치

모든 통신은 암호화(HTTPS)되며, 캘린더 데이터와 사진은 행 단위 접근 제어로 본인과 연결된 상대방만 볼 수 있습니다. 사진은 1시간 동안만 유효한 주소로 보여 줍니다.
